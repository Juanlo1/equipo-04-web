# Guía de contribución para equipo-04-web

¡Gracias por  colaborar con nosotros! Para mantener el orden, sigue estas pautas:

## Convención de ramas
- Usa prefijos según el tipo de cambio: `fix/nombre-tarea` para correcciones o `feature/nombre-tarea` para nuevas características.
- Ejemplo: `fix/texto-alternativo-imagenes`.

## Formato de commits
- Escribe mensajes claros e imperativos (en español).
- Ejemplo: `Añade atributo alt a las imágenes de la cabecera`.
or querer colaborar en nuestro proyecto!
## Requisitos para la Pull Request
- Asegúrate de que la PR incluye una breve descripción de **qué cambiais** y **el por qué**.
- Vincula el issue correspondiente añadiendo al final: `Closes #N`.
